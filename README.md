# IT Portfolio Start
 
Учебный проект, в разработке.
 
## Название и цель
Адаптивная форма записи на консультацию. Проект показывает,
как оформить понятную форму с проверкой полей. Для кого:
учебная демонстрация навыков начинающего frontend-разработчика.
 
## Планируемый результат
Пользователь открывает страницу на телефоне или компьютере,
заполняет форму и видит понятные сообщения об ошибках
или подтверждение отправки.
 
## Моя роль
Я лично выполню вёрстку, проверку полей на JavaScript
и оформление README. Покажу навыки: HTML, CSS, JavaScript, Git.
 
## План работы
1. Подготовить разметку и адаптивные стили.
2. Добавить проверку полей и сообщения об ошибках.
3. Проверить на телефоне, добавить скриншоты и инструкцию запуска.
 
Статус: шаг 1, в работе.
 
## Проверка результата
Открыть страницу, оставить поле пустым и убедиться, что появилось
сообщение об ошибке; затем заполнить форму верно и увидеть
подтверждение.
